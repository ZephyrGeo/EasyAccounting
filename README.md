# Snowflake ❄️

Snowflake is a modern, minimalist personal finance tracker built with React, TypeScript, and Vite.

## Features

- **Dashboard**: Real-time overview of your finances.
- **Transactions**: Easy management of your daily expenses and income.
- **Analytics**: (Coming soon) Visualize your spending patterns.
- **Mobile Friendly**: Fully responsive design for on-the-go tracking.

## Tech Stack

- **Frontend**: React 19, TypeScript, Tailwind CSS 4.
- **Icons**: Lucide React.
- **Charts**: Recharts.
- **Build Tool**: Vite.

## Getting Started

1. Clone the repository
2. Install dependencies: `npm install`
3. Start development server: `npm run dev`
4. Build for production: `npm run build`
