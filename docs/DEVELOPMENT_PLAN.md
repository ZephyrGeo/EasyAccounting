# EasyAccounting 核心功能优化与 AI 增强计划

## 1. 修复 Total Expense 的副标题 (High Priority)
目前 Dashboard 顶部的总支出卡片（MetricCard）在显示对比数据时逻辑不够直观或存在显示偏差。
*   **详细扩展**：
    *   **数据对齐**：确保 `useMonthlyComparison` 钩子能够准确获取“上月同一日期区间”的支出，而不仅仅是全月总计，以实现真正的同比。
    *   **UI 强化**：副标题应动态显示为 `Compared to ¥[金额] last month`，并配以颜色标识（支出减少为绿色，增加为红色/橙色）。
    *   **边界处理**：处理新用户第一个月无数据时的“暂无对比”状态。

## 2. 日期选择器样式优化与区间选择 (Low Priority)
目前的月份切换较为基础，无法支持跨月份或自定义区间的财务分析。
*   **详细扩展**：
    *   **区间支持**：重构 `useSelectedMonth` 为 `useDateRange`，支持 `startDate` 和 `endDate`。
    *   **预设快捷键**：增加“最近 7 天”、“本季度”、“本年度”的快速筛选功能。
    *   **样式升级**：采用悬浮式日历或更现代的分段控制器（Segmented Control）。

## 3. Weekly Spending Comparison 替换 (Medium Priority)
当前的周对比图表可能无法直观反映消费节律。
*   **替代方案建议**：
    *   **方案 A：累积消费曲线 (Cumulative Spending)**：将当月消费轨迹与上月对比，直观看到消费在月中哪个节点突然“陡增”。
    *   **方案 B：日均支出分布**：分析工作日 vs 周末的消费习惯。
    *   **方案 C：分类趋势流图 (Streamgraph)**：查看不同分类随时间变化的占比。

## 4. 完善交易记录 Row 功能 (High Priority)
将静态的列表项转变为功能丰富的交互单元。
*   **详细扩展**：
    *   **快速操作栏**：Hover 或点击时显示“编辑”、“删除”、“复制”图标。
    *   **快速打标 (Quick Tagging)**：在 Row 中直接点击 `+` 号弹出常用标签云，实现免跳转打标。
    *   **备注预览**：在商户名下方以浅色小字显示备注，若备注过长则自动截断。
    *   **支付账户标识**：增加支付来源标识（如 Visa、现金、支付宝图标）。

## 5. AI 自动记账与商家库建设 (Critical Priority)
这是项目的核心竞争力，涉及从视觉识别到数据治理的全链路。
*   **详细扩展**：
    *   **AI 解析引擎**：利用 LLM (如 Claude 3.5 Sonnet) 解析上传的图片/PDF，返回标准的 JSON 交易数组。
    *   **商户标准化 (Normalization)**：
        *   建立 `normalizeMerchantName` 工具函数，利用正则剔除 `P3391A120F` 等交易杂质。
        *   **逻辑优化**：优先匹配本地已有的 `merchants` 库，若无则进行模糊推测。
    *   **Logo 自动化集成**：
        *   调用 Logokit API 搜索商户官方图标。
        *   **存储流**：获取图片 -> 下载至 Supabase Storage -> 更新 `merchants.logo_url`。
    *   **分类推理**：根据商户名和金额大小，让 AI 预填分类，并显著标记为“AI 建议”，等待用户一键确认。
