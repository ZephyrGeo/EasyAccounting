# 商家名称自动复用方案 (Merchant Reuse Plan)

## 背景
当前 AI 在分析账单时，可能会为同一个商家生成略有不同的名称（例如 "FamilyMart" vs "Family Mart"），导致数据库中出现重复记录。为了保持数据的一致性，我们需要让 AI 在分析时参考数据库中已有的商家名称。

## 实施步骤

### 1. 数据获取层 (`src/lib/claude-api.ts`)
- **新增函数 `getExistingMerchants`**: 
  - 从 Supabase 的 `merchants` 表中查询所有已有的商家名称和关联品牌。
  - 考虑到性能，初步限制获取最近使用的或最常用的前 200 个商家。
- **更新解析逻辑**:
  - 在 `parseCsvWithClaude` 和 `parsePdfWithClaude` 开始解析前，先调用此函数获取商家列表。

### 2. 提示词增强 (`src/lib/prompts.ts`)
- **修改 `EXPORT_PROMPT`**:
  - 增加一个变量占位符 `{{EXISTING_MERCHANTS}}`。
  - 在“核心逻辑”中增加一条指令：
    > "如果你在账单中识别出的商家与【已有商家列表】中的某项高度相似或语义一致，**必须优先使用已有列表中的名称**，以确保数据库唯一性。"

### 3. AI 调用层逻辑优化
- 在调用 Claude API 之前，将获取到的商家列表格式化为字符串，并替换 Prompt 中的占位符。

### 4. 验证与测试
- **测试用例**: 上传包含 "7-11" 的账单，如果数据库中已有 "7-Eleven"，验证 AI 是否会自动修正为 "7-Eleven"。
- **异常处理**: 如果数据库为空，确保 AI 依然能正常工作并生成新的名称。

## 预期效果
- 显著降低商家重名率。
- 提高统计图表的准确性（不再因为名称微差被拆分为两条记录）。
- 提升用户的账单管理体验。
